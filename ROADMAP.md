# Roadmap

All items after Phase 1 are **PLANNED**, not completed.

## Phase 1: Current prototype (done)
- Single-file HTML app with interactive dashboards
- Simulated authentication, OTP and Google sign-in
- Department and disease workflows, 4 languages, click-only voice
- Hospital navigation (4 floors, wheelchair routing)
- Queue board and doctor schedule (simulated data)
- Patient tracking by token, token QR
- Emergency interface with route management (simulated)

## Phase 2: Backend development (PLANNED)
- Secure authentication (OTP/SMS, OAuth) and role-based access
- REST API and database (patients, staff, doctors, schedules, appointments, alerts)
- Persistent hospital data and appointment booking, rescheduling, history

## Phase 3: AI integration (PLANNED)
- Real AI assistant with context-aware patient guidance
- Multilingual conversational assistance
- Responsible AI safeguards: no diagnosis, no prescriptions, clear escalation to staff

## Phase 4: Hospital integration (PLANNED)
- Real-time queue and doctor updates
- Doctor scheduling and hospital information system integration
- Push/SMS notifications to staff and relatives
- Analytics dashboards (department load, waiting time, patient flow)

## Phase 5: Production readiness (PLANNED)
- Security audit and penetration testing
- Privacy compliance review (e.g. DPDP, HIPAA, GDPR as applicable)
- Performance optimization and automated tests
- Accessibility testing with real users (WCAG)
- Deployment, monitoring and incident response
